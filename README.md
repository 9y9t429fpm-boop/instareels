# instareels — парсер идей из рилсов + идеи для Архстояния 2026

Набор инструментов, чтобы:

1. **Спарсить рилсы** со своего аккаунта Instagram и из сохранённых (captions, статистика, ссылки).
2. **Выжать из них суть** — основные идеи, форматы и хуки (через Claude API).
3. **Идеи для рилсов на Архстоянии 2026** — готовый файл [`IDEAS_ARCHSTOYANIE.md`](IDEAS_ARCHSTOYANIE.md).

## Быстрый старт

```bash
pip install -r requirements.txt
```

### Шаг 1. Логин в Instagram (один раз)

Instagram не отдаёт сохранённые посты без авторизации, поэтому нужна сессия:

```bash
python parse_reels.py --login ВАШ_ЮЗЕРНЕЙМ
# спросит пароль, сохранит сессию в ~/.config/instaloader/
```

> ⚠️ Запускайте со своего компьютера/телефона (Termux тоже работает) — с серверных
> IP Instagram часто блокирует вход. Если включена 2FA, instaloader попросит код.

### Шаг 2. Парсинг

```bash
# свои рилсы + сохранённые (по умолчанию максимум 200 и 200)
python parse_reels.py --user ВАШ_ЮЗЕРНЕЙМ

# только сохранённые, максимум 50
python parse_reels.py --user ВАШ_ЮЗЕРНЕЙМ --only saved --limit 50
```

Результат: `data/reels.json` — список рилсов с caption, ссылкой, датой, лайками и просмотрами.

### Шаг 3. Выжимка идей

Нужен ключ Claude API (`export ANTHROPIC_API_KEY=...`):

```bash
python extract_ideas.py
```

Результат: `data/ideas_from_my_reels.md` — по каждому рилсу: главная идея, формат, хук;
плюс общая сводка: какие темы/форматы у вас повторяются и что из этого можно
переиспользовать на Архстоянии.

## Запасной вариант без парсинга: экспорт данных Instagram

Если логин через instaloader не проходит:

1. Instagram → Настройки → **Скачать свою информацию** → формат **JSON**.
2. Распакуйте архив и запустите:

```bash
python parse_reels.py --export путь/к/распакованному/архиву
```

Скрипт вытащит ваши рилсы и сохранённые из файлов экспорта в тот же `data/reels.json`.
